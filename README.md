# Tasker — Веб-приложение для управления задачами и проектами
Учебный проект, разработанный в рамках учебной практики на стеке **Next.js (App Router), TypeScript, Tailwind CSS, Prisma ORM и SQLite**.
Разработка удобного и быстрого веб-приложения для управления личными и учебными задачами (Todo-менеджер) 
с возможностью их группировки по отдельным проектам, 
позволяющего пользователю структурировать планы, отслеживать статус выполнения задач и соблюдать сроки.

## Основной функционал
- Защита доступа к приложению и API по паролю (через `middleware.ts` и HttpOnly cookies).
- Создание, просмотр и каскадное удаление проектов.
- Добавление задач внутри проекта с указанием срока выполнения (дедлайна).
- Изменение статуса выполнения задачи (выполнено / в работе), фильтрация и удаление.
- Пользовательская страница обработки ошибок 404 (`app/not-found.tsx`).

### Пользовательские сценарии:

* **Сценарий 1** (Просмотр и создание проекта): Пользователь открывает главную страницу, 
видит карточки своих проектов, вводит название нового проекта в форму и нажимает «Создать» - проект появляется в списке.

* **Сценарий 2** (Переход к задачам): Пользователь кликает по карточке нужного проекта и попадает на страницу, 
где видит список всех задач именно этого проекта.

* **Сценарий 3** (Работа с задачами): Внутри проекта пользователь добавляет новую задачу (название и дедлайн),
 отмечает готовые задачи галочкой, фильтрует список (все / активные / выполненные) или удаляет ненужную задачу.
 
* **Сценарий 4** (Удаление проекта): Пользователь удаляет завершённый проект вместе со всеми его задачами.

### Структура базы данных
* **Project (Проекты):** `id` (PK), `title` (название), `description` (описание), `createdAt` (дата создания).
* **Task (Задачи):** `id` (PK), `title` (текст задачи), `isCompleted` (статус выполнения), `deadline` (срок выполнения), `projectId` (FK на Project), `createdAt`.
* **Связь:** один ко многим (`1:N`) — один проект может содержать множество задач, при удалении проекта задачи удаляются каскадно.

## Запуск проекта после клонирования
1. Установить зависимости:
   `npm install`
2. Создать файл `.env` по образцу `.env.example`.
3. Применить миграции и создать базу данных SQLite:
   `npx prisma migrate dev`
4. Заполнить базу тестовыми данными:
   `npx tsx prisma/seed.ts`
5. Запустить сервер разработки:
   `npm run dev`
6. Открыть в браузере `http://localhost:3000` (пароль по умолчанию: `1234`).
